# 용어집

| 항목 | 내용 |
|---|---|
| 적용 범위 | 제품 이름의 모든 문서와 코드 |
| 참고 문서 | 이 문서가 근거로 삼은 문서. 링크로 적는다. `[요구사항 정의서](../prd/orders.md)` |

이 문서는 이 제품에서 쓰는 말을 하나로 정한다. 같은 것을 문서마다 다르게 부르거나, 한 단어가 두 뜻으로 쓰이는 일을 막는다. 용어마다 뜻, 대신 쓰지 않을 말, 코드와 DB에서의 이름을 적는다. 문서와 코드는 여기 정한 이름만 쓴다.

각 절 아래의 설명은 무엇을 어떻게 쓰는지에 대한 안내다. 문서를 완성할 때 지운다.

## 용어

가나다순으로 적는다. 뜻은 한 문장으로, 이 제품에서의 의미로 쓴다.

작성 예:

| 용어 | 뜻 | 쓰지 않을 말 | 코드·DB 이름 |
|---|---|---|---|
| 결제 시도 | 주문 하나에 대해 결제 대행사에 결제를 요청한 한 번의 기록 | 결제 이력, 트랜잭션 | `payment_attempts`, `PaymentAttempt` |
| 담당자 | 주문을 조회하고 결제 실패를 처리하는 운영팀 역할 | 운영자, 오퍼레이터 | `role = 'operator'` |
| 재시도 | 결제 실패 주문의 결제를 다시 요청하는 것 | 재결제, 재처리 | `payment_retry` |
| 주문자 | 쇼핑몰에서 주문을 한 고객 | 구매자, 고객 | `orderer_name`, `orderer_phone` |
