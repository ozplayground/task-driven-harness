# run 이름 — 진행 기록

이 파일은 run을 진행하면서 내린 결정, 세운 가정, 사용자에게 한 질문과 받은 답, 요청 밖 발견, 비판 항목 처리를 시간순으로 남기는 곳이다. 리더가 쓴다. 한 줄에 한 항목이고 덧붙이기만 한다. 이미 쓴 줄은 고치지 않는다. 틀린 것을 알게 되면 "정정" 항목을 새로 덧붙인다. 항목마다 날짜, 종류, 내용, 출처를 적는다.

종류는 다음 중 하나다. 사용자(사용자가 한 말이나 답), 결정(리더나 아키텍트가 내린 결정), 가정(답이 없어 임시로 정한 것), 질문(사용자에게 올린 것), 발견(요청 밖에서 나온 문제), 비판 처리(critic 항목을 어떻게 처리했는지), 정정.

- 2026-09-18 결정 큐는 procrastinate로. architect 추천, critic r1 무이의, reviewer 비평 confirmed — ADR-002
